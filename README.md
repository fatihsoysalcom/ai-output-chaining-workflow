# AI Output Chaining Workflow

This example demonstrates how to chain the outputs of different "AI features" to create a complete workflow. It simulates text generation, sentiment analysis, and action recommendation, where the output of one step feeds directly into the next. This illustrates the article's core concept of connecting AI outputs for greater value.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal using `python main.py`.
